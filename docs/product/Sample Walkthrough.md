# Sample walkthrough — Asana Agent

This public walkthrough uses the fictional Northstar board. It has no Asana connection, external AI service, or task-system account; confirmed changes stay in this browser. Start from the original fixtures: choose **Reset sample**, review the replacement preview, and confirm it. Reset replaces local browser edits.

1. In **Workspace**, choose **What is blocked?**. The guide answers from the visible task cards and identifies **NTH-108 — Instrument workspace-created event** and **NTH-119 — Summarize churn interviews**. This is a read request: no change preview opens.
2. Ask **When is Validate admin invite flow due?**. The response grounds the answer in **NTH-115** and its Sep 11 sample due date. Then ask **Mark that done**. Because NTH-115 was the clear preceding task, the guide prepares a status proposal instead of changing it. Select **Cancel**. Now ask **What is blocked?**, followed by **Mark that done**. The board-wide answer expires the earlier NTH-115 context, so the guide asks which task you mean and opens no proposal.
3. For the primary update, enter **Mark Finalize onboarding checklist as done**. The preview pairs **NTH-104** with **Finalize onboarding checklist** and shows **Status: In progress** before **Status: Complete**. Select **Cancel** once to confirm the card remains In progress; repeat the request and select **Confirm change** to apply the local sample update.
4. Use the Owner menu on **Review trial nurture copy** and choose **Jon Bell**. The same preview pattern shows **Priya Shah → Jon Bell** before confirmation. Select **Confirm change**. Direct controls do not bypass the conversation safety boundary.
5. Choose **Undo last change**. Undo itself opens a preview; confirm it to restore the preceding NTH-112 owner. Reset sample follows the same reviewed path before replacing browser state.
6. Choose **Complete tasks in review** while NTH-112 is In review. The preview lists every affected task before it can proceed. **Clear chat** removes only conversation messages; it does not close a preview or mutate a task; select **Cancel** to close the bulk preview.

The intended tradeoff is visible friction in exchange for a reviewable update. Whether real users understand and value that tradeoff is unanswered; the proposed study compares it with each participant’s current workflow before broader language support, integrations, or automation.
