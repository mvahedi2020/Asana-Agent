# Asana Agent

## 🚀 Product Vision
An AI-powered project management assistant that integrates seamlessly with Asana to automate task triaging and sprint planning.

## 🎯 Target Personas
- **The Overwhelmed PM:** Needs to prioritize 100+ backlog items instantly.
- **Engineering Leads:** Needs to track sprint velocity without manual Jira parsing.

## 🛠️ Tech Stack Note
As a Product Manager, I partnered with engineering to scaffold this MVP using modern standards: **Next.js 15 (App Router), React 19, and Tailwind CSS**.
