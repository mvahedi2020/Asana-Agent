# Contributing

Keep this repository a safe, standalone sample. Do not add real customer data, credentials, third-party API calls, analytics, or claims of measured impact.

## Local setup

Install dependencies with `npm install`, then start the demo with `npm run dev`. The Vite production base is `/Asana-Agent/`. Browser state uses the versioned key `northstar.asana-agent.v1`.

Before opening a change, run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`. Preserve confirmation before every mutation, keyboard access, semantic labels, plain-text React rendering, responsive layouts, the versioned storage key, and honest plain-English responses. Do not make task codes mandatory, silently choose an ambiguous task, or let a direct control bypass review. Update product documentation when behavior or definitions change.

Run the browser workflows with `npm run test:e2e`. Local runs use the installed Chrome channel; CI installs and uses Playwright Chromium. Set `CAPTURE_MEDIA=1` to retain workflow screenshots and videos.
